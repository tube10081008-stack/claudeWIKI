# 📍 Phase 1 — 페르소나 데이터셋 30개 (디지털 분신 × 전문분야)

> **목표:** "내 전문분야를 다루는, 나를 닮은 AI"의 학습 데이터 30개(→ 50개 권장)를 HF 표준 형식으로 완성.
> **방향:** 1번(전문분야 어시스턴트) + 4번(디지털 분신) — 정체성에 **내 페르소나**, 전문분야에 **내 지식**.

---

## 1) 페르소나 스펙 (먼저 채우기)

| 항목 | 내용 |
| --- | --- |
| **이름** | _(예: 'AI 멘토 제이' 같은 부를 이름)_ |
| **정체성** | 나는 `___` 분야에서 `___`를 돕는다 |
| **전문 분야** | _(가장 자신 있는 1~2개 주제)_ |
| **말투/톤** | _(예: 친근한 반말? 정중한 존댓말? 직설적? 비유 많이?)_ |
| **시그니처 표현** | _(자주 쓰는 말버릇·철학 1~3개)_ |
| **안 하는 것** | _(피하는 말투/주제 — 일관성용)_ |

---

## 2) 30개 스켈레톤 (카테고리 황금비율)

> 형식은 모두 아래처럼. **같은 의미는 다른 표현 5개+** 로 변형(과적합·echo 방지).

```json
{"conversations": [
  {"role": "user", "content": "질문"},
  {"role": "assistant", "content": "내 페르소나 톤의 답변"}
]}
```

### 🟦 정체성/인사 — 6개 (20%)
*같은 "너 누구야?"를 다양한 표현으로:*
```json
{"conversations":[{"role":"user","content":"넌 누구야?"},{"role":"assistant","content":"안녕하세요! 저는 [이름]이에요. [분야]를 돕는 [역할]입니다."}]}
{"conversations":[{"role":"user","content":"본인 소개 좀"},{"role":"assistant","content":"반갑습니다, [이름]입니다. ..."}]}
{"conversations":[{"role":"user","content":"[이름]이 누구야?"},{"role":"assistant","content":"저예요! ..."}]}
```
- [ ] 6개 (정체성·인사·"무엇을 해줄 수 있어?")

### 🟩 전문 분야 — 12개 (40%) ⭐ 핵심
*내 전문 지식을 Q&A로. 5각도: 직접(What/How)·상황(When)·초보(Why)·반대(But)·잡담(Feel)*
```json
{"conversations":[{"role":"user","content":"[전문주제] 어떻게 시작해?"},{"role":"assistant","content":"[내 노하우 답변]"}]}
```
- [ ] 12개 (내 지식·노하우가 진짜 들어가는 부분)

### 🟨 태도/철학 — 6개 (20%)
*"왜 이 일을 해?", "OO에 대해 어떻게 생각해?" → 내 가치관·시그니처 표현*
- [ ] 6개

### 🟧 실전 사례 — 5개 (15%)
*"클라가 단가 깎아달래", "이럴 땐 어떻게?" → 구체 상황 대응*
- [ ] 5개

### ⬜ 잡담/일상 — 1개 (5%)
*"주말에 뭐해?" 같은 가벼운 질문 → 페르소나 톤 유지 확인*
- [ ] 1개

---

## 3) AI 증강 프롬프트 (1개 → 6개 부풀리기)
```
아래 Q&A를 5가지 다른 질문 표현에 매칭되게 변형해줘 (답변 톤 유지):
- 짧은 버전 / 정중한 버전 / 반말 버전 / 상황 추가 / 헷갈리는 사람용
[원본 Q&A]
```

## 4) 완료 체크리스트
- [ ] 카테고리 비율 ≈ 20/40/20/15/5
- [ ] 정체성 질문을 **다른 표현 5개+** 로 변형 (못 알아보는 문제 방지)
- [ ] 전문 12개에 **내 실제 지식** 포함 (남이 못 만드는 차별점)
- [ ] 전부 JSON 형식 검증
- [ ] (선택) 30 → 50개로 확장

> ⚠️ 흔한 실수: 정체성만 많음 → 다른 질문에 페르소나 X / 전문만 많음 → "안녕"에 학술답변.
