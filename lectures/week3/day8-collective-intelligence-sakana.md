## 7~9. 1인 기업가 실전 & 액션
1. **AI 한 개만 쓰지 마** — 코딩=Claude, 자동화=Gemini Flash, 검증=또 다른 모델(감독처럼 배치)
2. **나만의 모델을 만들어라** — 합치고(merge) + 내 데이터로 가르쳐(LoRA) → 남에게 없는 AI
3. **자율로 일하게** — 자는 동안 정리·백업·리서치
4. **0원부터** — 비싼 클라우드는 "미래 미리보기", 실제 손은 로컬 무료로
- 따라하기: chat.sakana.ai 체험 / OpenAI SDK `base_url` 교체 / Connect AI + Ollama로 로컬 집단지성 / **AI 두 개 합치기(model merging)** 노트북

# 🔍 분석 — "오늘 내가 만든 게 곧 이 강의의 프론티어다"

이 강의는 **오늘 세션에서 내가 직접 만든 것들을 그대로 검증**한다:

| 강의(Sakana) | 오늘 내가 만든 것 |
| --- | --- |
| 집단지성·오케스트라 지휘자 | **지오(총괄) + 코라·핀·오피·리나** 분신팀 / DTx **6에이전트 유기체** |
| Fugu = Thinker→Worker→Verifier | DTx 오케스트레이터 + Architect/Backend/Clinical… (지휘자→전문가) |
| "나만의 모델 (LoRA)" | **코라 LoRA 파인튜닝**(Qwen2.5-3B, Loss 0.55) |
| 자율/지식 | **성숙한 RAG 설계도 + PoC**(검색⇄추론, RAGAS) |
| 로컬·0원 해자 | LM Studio/Ollama 로컬 배포 계획 + 무료 Colab 학습 |

> ⭐ **결론: 강의가 "이게 프론티어다"라고 소개한 걸, 나는 오늘 하루에 손으로 만들었다.** 멀티에이전트 오케스트레이션·LoRA·RAG를 이미 코드로 굴렸으니, 강의의 "우리는 이미 하고 있다"가 나에겐 문자 그대로 사실.

### 아직 안 해본 딱 하나 = 다음 목표 🎯
- **🧬 모델 머징(Evolutionary Merge / mergekit / task arithmetic)** — 오늘 한 건 *LoRA(가르치기) + RAG(지식 붙이기)*였고, **여러 모델을 합쳐 새 모델을 만드는** 진화 병합은 미착수. Sakana 3무기 중 유일하게 안 건드린 조각 → 자연스러운 다음 실습.
  - 예: 코라(글쓰기) 모델 + 한국어 강화 모델을 `mergekit`으로 병합 → *추가 학습 없이* 둘 다 잘하는 모델.

### 비판적 시각 (오늘 우리가 나눈 논의와 연결)
- Fugu의 "Thinker/Worker/Verifier"는 **멀티에이전트 오케스트레이션** — 기법으론 이미 상식(우리가 "성숙 vs 프론티어"에서 정리한 그것). Sakana의 진짜 차별점도 *알고리즘*이 아니라 **제품화·통합·브랜딩("복어" 제품)**.
- "Fugu Ultra 73.7 > Opus 69.2"는 *팀워크가 개별 모델을 이긴다*는 우리 실측 감각과 일치 — 단, **측정(벤치)로 증명**한 게 핵심. (우리도 오늘 RAG를 숫자로 검증했지.)
- **우리의 진짜 해자 = 로컬·데이터주권.** 강의의 결론과 정확히 같음: 기술은 평준화됐고, 차별점은 *0원·프라이버시·니치·내 데이터*.
