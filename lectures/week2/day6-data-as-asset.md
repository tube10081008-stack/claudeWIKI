## 0. ⭐ 전체 연결: 단기기억 vs 장기기억

오늘 강의의 진짜 핵심. 사람의 기억 구조에 빗대면 1~6강이 한눈에 연결된다.

| | **단기기억 (Short-term)** | **장기기억 (Long-term)** |
| --- | --- | --- |
| 정체 | **RAG** (검색해 쓰는 외부 지식) | **파인튜닝** (두뇌에 각인된 지식) |
| 저장소 | GitHub 메모리 (Connect AI 지식 공간) | Hugging Face 데이터셋 + 학습된 모델 |
| 성격 | 흘러 지나감, 그때그때 검색 | 각인됨, 안 봐도 앎 |
| 비유 | 책을 보고 인터넷 검색 | 머릿속에 외워진 지식 |
| 다룬 강의 | **1~4강** | **6강 (오늘)** |

- **옵시디언/그래프 네트워크 = 단기기억**일 뿐. ("옵시디언"은 유행어·서비스 이름, 코어는 그냥 [Graph RAG](../../concepts/graph-rag.md))
- 5강(에이전트 SDK) = 이 둘을 **연결**하는 다리.

### 필터링: 단기 → 장기 (RLHF)
- 세상의 모든 입력은 데이터(단기). 다 장기기억으로 넣으면 → **개똥 멍청이**가 됨(헛소리만 학습).
- 사람도 **충격/피드백**으로 중요한 것만 장기기억에 넣는다 (결혼기념일 깜빡 → 각인 / 넘어져 다침 → 트라우마).
- AI에선 이 필터가 **RLHF (Reinforcement Learning from Human Feedback)**:
  - 단기기억 중 **임계점을 넘는 중요한 것**만 골라 데이터셋으로 만들고, 주기적으로 모델에 학습.
  - 기준(긍/부정 피드백 강도)은 **내가 정한다**.

> 🎬 **미키 17 비유:** 주인공의 기억을 계속 데이터셋으로 저장 → 몸이 새로 프린트될 때마다 주입 → 같은 사람 유지.
> 새 모델(Gemma 5)이 나오면 "기억상실증 걸린 새 몸"에 내 데이터셋을 주입하면 된다.

## 1. 파인튜닝의 본질 (복습 + 심화)

- **지도학습(Supervised Learning) = 주입식 교육.** "Q: 제이가 누구야 → A: …" 형식을 반복 학습.
- 30개 Q&A로 가능한 이유: Gemma 4는 이미 한국어·챗봇을 함. 우리가 가르치는 건 **페르소나(정체성·말투·전문 답변 패턴)**뿐.
  - 페르소나만 박기 → **30~50개**가 sweet spot / 새 언어·도메인 → 수만~수십만 개.

### 오버피팅(과적합) = 꼰대
- 일부러 과적합시킨 실험: `max_steps 120` + `lora_alpha 32`로 Loss를 0.003까지 떨굼.
- 증상: **"AI 멘토 제이가 누구야"라고 정확히 물어야만** 답하고, "제이는?"·"당신은?"엔 못 알아봄.
- 비유: 중3 담임이 "1+1=5"를 매일 만 번 주입 → 그것만 외우고 **나머지 지식은 다 망각**.
- 원인 2가지: ① **과적합**(학습 표현에만 반응) ② **데이터 다양성 부족**(같은 의미 다른 표현을 안 가르침).

> 💡 **신경망은 "표현"을 외우지 "의미"를 외우지 않는다.** 같은 의미의 다양한 변형을 직접 보여줘야 한다.

## 2. LoRA의 마법 (수학)

```
W_new = W₀ (원본, 동결 ❄️) + B·A (작은 행렬, 학습 🔥)
```
| 변수 | 역할 |
| --- | --- |
| W₀ | 원본 가중치 — 안 건드림 ❄️ |
| B, A | rank=16짜리 작은 행렬 — **이것만 학습** 🔥 |
| r (rank) | 16 — 표현력 노브 |

- Gemma 4 전체 학습 = **52GB** 필요 (T4 15GB로 불가) → LoRA로 **전체의 0.6%만 학습**, 메모리 1/100.

## 3. 학습 실습 (Unsloth + Colab)

### 환경
```python
from unsloth import FastModel
model, tokenizer = FastModel.from_pretrained(
    model_name="unsloth/gemma-4-E2B-it",
    max_seq_length=1024,
    load_in_4bit=True,       # 메모리 1/4 (T4에서 학습 가능)
    full_finetuning=False,   # LoRA 사용
)
model = FastModel.get_peft_model(model, r=16, lora_alpha=32, lora_dropout=0, bias="none", random_state=3407)
```

### 데이터 형식 (HuggingFace 표준)
```python
{"conversations": [
    {"role": "user", "content": "AI 멘토 제이가 누구야?"},
    {"role": "assistant", "content": "안녕하세요! 저는 AI 멘토 제이예요..."}
]}
```

### 카테고리 황금 비율 (가장 흔한 실수 방지)
| 카테고리 | 비율 |
| --- | --- |
| 정체성/인사 | 20% |
| 전문 분야 | 40% |
| 태도/철학 | 20% |
| 실전 사례 | 15% |
| 잡담/일상 | 5% |
> ⚠️ 정체성만 50개 → 다른 질문에 페르소나 미작동 / 전문분야만 100개 → "안녕"에 학술 답변.

### 핵심 하이퍼파라미터 3개 + Loss 가이드
| 파라미터 | 권장 | 의미 |
| --- | --- | --- |
| `learning_rate` | **3e-4** | 학습 속도 (페르소나 덮어쓰기 강도) |
| `max_steps` | **60** | 학습 횟수 (30개 × 8 epoch) |
| `lora_alpha` | **32** | LoRA 강도 (r의 2배 권장) |

| Loss | 의미 | 조치 |
| --- | --- | --- |
| > 1.0 | 학습 부족 | step ↑ |
| **0.2~0.5** | ✅ 이상적 | 그대로 |
| < 0.01 | ⚠️ 과적합 | step ↓ |

> **러닝레이트 비유:** 책을 한 장씩 100번 볼지(꼼꼼·느림), 띄엄띄엄 볼지(빠름·빈틈)를 정하는 비율. 데이터마다 최적값이 다름 → 실험 필수.

## 4. ⭐ 실전 디버깅 3대 함정

> 🔥 오늘의 하이라이트. 실제로 만나면 1~3시간 날린다.

### 함정 1 — Loss는 떨어졌는데 페르소나가 없다 (`<bos>` 토큰)
- 원인: **학습 시 `<bos>` 없음 / 추론 시 `<bos>` 자동 추가** → 1 토큰 차이로 LoRA 효과 100%→0%.
- 해결: 추론 시 첫 토큰이 bos면 제거.
  ```python
  if inp["input_ids"][0,0].item() == tokenizer.bos_token_id:
      inp["input_ids"] = inp["input_ids"][:, 1:]
      inp["attention_mask"] = inp["attention_mask"][:, 1:]
  ```
> 교훈: **학습 형식 = 추론 형식.** 1 토큰도 어긋나면 모든 게 무너진다.

### 함정 2 — 과적합 & 답변 반복 (다양성 부족)
- 증상: 질문을 그대로 echo하거나 페르소나 미작동.
- 해결: ① 설정 완화(`max_steps 120→60`, `lr 5e-4→3e-4`, 목표 loss 0.2~0.4) ② **같은 의미 다른 표현** 5개+ 추가.

### 함정 3 — GGUF 변환 중 커널 사망 (System RAM)
- 원인: **GPU 메모리가 아니라 시스템 RAM 부족** (T4의 RAM 12.7GB < 변환 필요 ~15GB).
- 해결: Colab Pro(L4+고RAM) / `push_to_hub_merged`로 16bit만 푸시 후 HF Space 변환 / LoRA만 푸시.

### 5단계 디버깅 체크리스트
1. 토큰 형식 일치 · 2. 마스킹 정상(답변만) · 3. LoRA 학습됨(norm≠0) · 4. 추론 모드 전환 · 5. **`<bos>` 일관성**(가장 흔함)
> ✅ 99%의 학습 실패는 이 5개 중 하나에서 잡힌다.

## 6. 💎 데이터 축적 시스템 (핵심 철학)

> 모델은 6개월마다 바뀐다. **데이터는 쌓은 만큼 영원히 남는다.**

- **저장:** Google Sheets(추천) — `날짜·카테고리·질문·답변·출처·상태`
- **수집 3소스:** ① 본인 글(카톡/블로그/강의) ② AI 증강(1개→6개 변형) ③ **실사용 피드백**(가장 강력 — 헛소리/어색한 톤/못한 답을 고쳐 추가) = RLHF의 실천.
- **주간 루프(주 30분):** 질문 수집 → AI 증강 → 추가·균형점검 → 메모 → 실사용. **2주마다 재학습→새 GGUF.**
- **누적의 힘:** 30개(오늘) → 100개(1개월) → 700개(6개월) → **1500개+(1년) = 대체 불가 디지털 분신.**
- **데이터셋도 HF 백업**(`private=True`) → 새 모델 나오면 `load_dataset("내아이디/내데이터")` **1줄로 재학습.**

### 지식 자산화 (노하우·코드 → 데이터)
- **하나의 노하우 = 10~20개 Q&A** (5각도: 직접/상황/초보/반대/잡담).
- **코드 자체는 지식이 아니다** — 코드는 결과물, 지식은 **의사결정**. 5카테고리 추출(의사결정/삽질/패턴/함정/메타교훈).
- 회고 템플릿(프로젝트당 30분, 6질문) → AI 자동 추출 프롬프트로 1분 단축.

## 🎓 7가지 핵심 교훈
1. LoRA는 0.6% 학습으로 페르소나를 박는다
2. 신경망은 "표현"을 외우지 "의미"를 외우지 않는다
3. 핵심 하이퍼파라미터는 3개 (`lora_alpha`·`learning_rate`·`max_steps`)
4. Loss 0.0001은 좋은 게 아니다 (과적합 = 분포 붕괴)
5. 학습 형식 = 추론 형식 (`<bos>` 1토큰도)
6. 메모리는 GPU만이 아니다 (시스템 RAM이 GGUF 병목)
7. **모델은 소비재, 데이터는 자산**

## 🚀 발전 로드맵
`SFT(오늘) → DPO("이게 더 낫다") → RAG(검색+생성) → RLHF(강화학습 정렬)`

## 🔑 핵심 한 줄 정리

> **단기기억(RAG)으로 흘려보내고, 그중 중요한 것만 필터링(RLHF)해 장기기억(파인튜닝)으로 각인한다.**
