## 🔑 핵심 개념 치트시트

| 개념 | 한 줄 |
| --- | --- |
| **Antigravity SDK** | CLI=쓰는 비서, SDK=비서 서비스를 만드는 재료 |
| **하이브리드 비용 최적화** | 로컬 요약→클라우드 최종, ~98% 절감 |
| **단기 vs 장기 기억** | RAG(검색) vs 파인튜닝(각인), RLHF로 필터링 |
| **데이터 자산화** | "모델은 소비재, 데이터는 자산", 누적의 힘 |
| **파인튜닝 3대 함정** | `<bos>` 토큰 / 과적합·다양성 / GGUF RAM |
| **멀티에이전트** | 많아질수록 멍청 → 지식 공유가 답 |
| **3대 공유 패턴** | 공유게시판(MetaGPT)·공유환경(AgentVerse)·생각교환(EoT) |
| **학습 패러다임** | 지도(SFT)·비지도·강화학습 |

## ⭐ 가장 중요한 통찰
> **모델이 아니라 데이터가 자산.** 단기기억으로 흘려보내고, 검증된 핵심만 장기기억으로 각인하며,
> 여러 에이전트가 그 지식을 공유할 때 비로소 대체 불가능한 집단지성이 만들어진다.
