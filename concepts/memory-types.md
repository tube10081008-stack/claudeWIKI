# 파라메트릭 vs 논파라메트릭 메모리

2020년 Lewis 논문은 AI가 모든 지식을 머릿속에 넣는 데 한계가 있다고 보고, 두 메모리를 결합했다.

## 파라메트릭 메모리 (Parametric Memory)
- AI가 **이미 학습해서 알고 있는** 언어 능력 (머릿속 지식).
- 예: Gemini에 아무 문서 없이 그냥 질문할 때.
- = 일반적인 LLM의 답변.

## 논파라메트릭 메모리 (Non-parametric Memory)
- 실시간으로 꺼내 쓰는 **외부의 방대한 지식 창고** (외부 도서관).
- 예: PDF·위키피디아·유튜브 등을 업로드/연결해서 함께 쓸 때.
- "~이 아닌(non) 메모리" = 모델이 원래 가지지 않은 메모리.

## 핵심
> **지식 구조체(논파라메트릭)만 잘 만들어두면, 어떤 모델(파라메트릭)을 붙이든
> 나만의 결과물을 생성할 수 있다.** 모델은 바뀌어도 내 지식은 자산으로 남는다.

## 도구별 매핑 (강의 실습)
- NotebookLM에 PDF 추가 → 논파라메트릭 메모리 사용
- 빈 노트북/일반 Gemini → 파라메트릭 메모리만 사용
