# 멀티에이전트 (Multi-Agent)

**한 줄 정의:** 여러 AI 에이전트가 협력해 목표를 달성하는 연구. "자동화 에이전트"의 진짜 근간.

## 핵심
- 강화학습(알파고)의 핵심이 에이전트 → 여러 에이전트가 **어떻게 지식을 쌓고·공유하고·목표를 달성**할까.
- 일반 대화형 AI와 달리 에이전트는 **도구(tools)**를 갖춘다.

## ⚠️ 역설: 많아질수록 멍청해진다
- 에이전트가 100·1000개로 늘면 더 똑똑해져야 하는데 **무한 채팅·잡소리**만 늘고 핵심 일을 못 함.
- 해결책 = **지식 공유** ([지식 공유 패턴](./knowledge-sharing-patterns.md)).

## 집단지성 (Collective Intelligence)
- 영화 〈군체〉: 멍청한 좀비가 **하나의 기억을 공유**하며 학습·진화 ("마네킹은 사람 아님"을 한 마리가 깨달으면 전체 학습).
- 개미 집단지성·아이로봇·웨스트월드와 같은 결.
- → 한 사람의 지식에서 **여러 전문가의 검증된 지식이 모인 커뮤니티 네트워크**로 진화.
