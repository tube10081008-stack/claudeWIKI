# 단기기억 vs 장기기억 (Short-term vs Long-term Memory)

**한 줄 정의:** RAG = 흘러 지나가는 단기기억(검색해 씀), 파인튜닝 = 각인된 장기기억(두뇌에 학습됨). 6강의 핵심 프레임.

## 비교
| | 단기기억 | 장기기억 |
| --- | --- | --- |
| 정체 | **RAG** | **파인튜닝** |
| 저장소 | GitHub 메모리 (Connect AI 지식공간) | Hugging Face 데이터셋 + 학습된 모델 |
| 성격 | 그때그때 검색, 흘러감 | 각인됨, 안 봐도 앎 |
| 비유 | 인터넷 검색·책 펴보기 | 머릿속에 외워진 것 |

> 옵시디언/그래프 네트워크 = 단기기억일 뿐. "옵시디언"은 서비스 이름, 코어는 [Graph RAG](./graph-rag.md).

## 필터링: 단기 → 장기 (RLHF)
- 세상의 모든 입력은 데이터(단기). **다 장기로 넣으면 헛소리만 학습한 멍청이**가 됨.
- 사람은 **충격/피드백**으로 중요한 것만 각인 (결혼기념일 깜빡 / 넘어져 다침 = 트라우마).
- AI의 필터 = **RLHF (Reinforcement Learning from Human Feedback)**:
  - 단기기억 중 **임계점을 넘는 중요한 것**만 데이터셋화 → 주기적으로 모델에 학습.
  - 긍/부정 피드백 강도 기준은 **내가 정한다**.

## 미키 17 비유
- 기억을 데이터셋으로 저장 → 몸이 새로 프린트될 때마다 주입 → 같은 사람 유지.
- 새 모델(Gemma 5)이 나오면 "기억상실증 걸린 새 몸"에 내 데이터셋을 주입.
