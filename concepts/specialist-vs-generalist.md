# 스페셜리스트 vs 제너럴리스트 (에이전트별 전문 두뇌)

**한 줄 정의:** 모든 지식을 한 모델에 담은 제너럴리스트 대신, 에이전트 역할별로 특화된 두뇌(스페셜리스트)를 따로 학습·연결한다.

## 구분
| | 제너럴리스트 | 스페셜리스트 |
| --- | --- | --- |
| 학습 | 모든 카테고리 한꺼번에 | 한 분야만 |
| 예 | 전체 지식 다 아는 두뇌 | 코더=코딩만, 디자이너=디자인만 |

## 왜 나누나
- 에이전트마다 역할이 다름(디자이너·연구·운영·인스타·코더…).
- 카테고리(마케팅·코딩·사업·일반…)로 지식을 분류 → **에이전트별 특화 모델**을 따로 학습.
- 각 에이전트에 알맞은 두뇌를 끼우면 [컴퓨테이션 효율](./local-vs-cloud-llm.md)↑, 성능↑.

## 임계점 (Critical Mass)
- 양질의 **코어 지식**을 먼저 갖춰야(손흥민의 기본기처럼) 이후 지식이 들어와도 잘 확장.
- 처음부터 중구난방으로 쌓으면 오히려 멍청해진다.
