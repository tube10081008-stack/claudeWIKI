# Graph RAG

**한 줄 정의:** 지식을 점(點)으로 흩뿌리지 않고 선(線)으로 연결한 그래프로 만들어, 전체 맥락(숲)을 보는 RAG. (Microsoft Research)

## 왜 나왔나 — Vector RAG의 한계
- [벡터 RAG](./encoder-vector.md)는 **로컬 검색**에 강함. (예: "삼성 스마트폰 출시 연도?" 같은 정확한 키워드)
- 하지만 **전역적 질문**("이 데이터셋의 주요 트렌드는?", "1만 권 핵심 3가지")엔 약함 → 결국 전부 읽어야 함.

## 해결: 점 → 선 → 그래프
- 점들을 **관계로 연결**하고, **엔티티(특징)**와 **관계**를 추출.
- 나무가 아니라 **숲(전체 맥락)**을 본다. **마인드맵**과 유사.

## 핵심: 태그(Tag) 기반
- 검색 기반이 **태그/키워드 분류·연결**.
- **YouTube 알고리즘**이 Graph RAG 기반 → 영상에 태그를 다는 이유.

## 6단계 파이프라인
1. **Chunking** — 소스 문서를 청크로 잘게 나눔 (예: 600토큰 단위)
2. **Entity 추출** — 핵심 단어 뽑기
3. **지식 그래프 구축** — 점들을 관계로 연결
4. **커뮤니티 감지** — Hierarchical Partitioning (루트→서브→세부, 예: 지구→한국→강남구)
5. **커뮤니티별 요약**
6. **Map-Reduce 응답 생성** — 중요한 것만 추려 글로벌 답변
