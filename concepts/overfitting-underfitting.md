# 과적합(Overfitting) · 과소적합(Underfitting)

**한 줄 정의:** 모델 학습량이 너무 많거나(과적합) 너무 적을 때(과소적합) 생기는 문제. '적절한 학습량'이 핵심.

## 비교
| | Overfitting (과적합) | Underfitting (과소적합) |
| --- | --- | --- |
| 원인 | **너무 많이** 학습 | **너무 적게** 학습 |
| 증상 | 학습한 것만 완벽, 새 데이터엔 유연 X | 학습 데이터조차 제대로 인식 X |
| 비유 | **꼰대** (자기가 아는 게 다 정답) | 대충 훑어봐서 모름 |

## 비유: 화장품 스마트팩토리
- 화장품 1000개를 완벽 인식하게 학습 → 새로 추가된 10개는 학습이 안 됨(꼰대화) = 과적합.
- → 일주일 학습은 과해서 굳어버리고, 하루 학습은 부족해서 인식 못 함 → **중간 지점**을 찾아야.

## 시사점
- **파라미터 조절로 적절점을 찾는 '감'**이 곧 비즈니스 경쟁력.
- [Loss](./training-params.md)가 평균적으로 감소하되, 과하게 학습해 과적합되지 않도록 관찰.
