# Hugging Face

**한 줄 정의:** AI계의 GitHub. 약 258만 개의 인공지능 모델·데이터·Spaces를 대부분 무료로 공유하는 공간.

## 구성
- **Models** — 인공지능 모델 앱스토어
- **Datasets** — 데이터
- **Spaces** — 모델을 직접 실험해볼 수 있는 데모 공간

## Task(기능)별 6대 분류
| 분류 | 설명 |
| --- | --- |
| Multimodal | 여러 형식 한 번에 |
| Computer Vision | 이미지 생성/분류 |
| NLP | 글 생성 |
| Audio | 음악·음성 생성 |
| Tabular | 엑셀/표 데이터 |
| Reinforcement Learning | 강화학습 |

## 정렬(Sort) 기준
Trending · Most likes · Most downloads · Recently created · Recently updated ·
**Most parameters**(고성능·컴퓨팅 多) · **Least parameters**(가벼움, 스마트폰 가능)

## 라이선스 (사업화)
- **Apache 2.0** = 상업적 사용·수익화 모두 허용 (약 44만 개, Gemma 4 포함).
- 라이선스로 필터링해 **상업 가능 모델만** 골라 만들어 팔 수 있다.

## 실행과의 관계
- Hugging Face = 모델 모아놓는 곳. [Ollama/LM Studio](./local-vs-cloud-llm.md)로 쉽게 실행.
