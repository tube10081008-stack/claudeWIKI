# 데이터 자산화 (Data as Asset)

**한 줄 정의:** "모델은 소비재, 데이터는 자산." 모델은 6개월마다 바뀌지만, 내가 쌓은 데이터셋은 영원히 남는 대체 불가 자산이다.

## 핵심 철학
- 인공지능 모델은 계속 나오고 평준화됨 → 차별화는 **나만의 지식·노하우가 담긴 데이터**.
- 데이터는 **복리처럼** 쌓일수록 강력해진다.

## 데이터 축적 시스템
- **저장:** Google Sheets(추천) — `날짜·카테고리·질문·답변·출처·상태`
- **수집 3소스:**
  1. 본인 글 (카톡/블로그/강의 → Q&A)
  2. AI 증강 (1개 → 6개 변형: 짧은/정중한/반말/상황추가/헷갈리는용)
  3. **실사용 피드백** (가장 강력) — 헛소리·어색한 톤·못한 답을 고쳐서 추가 = [RLHF](./short-vs-long-term-memory.md)의 실천
- **주간 루프(주 30분):** 질문 수집 → AI 증강 → 추가·균형 점검 → 메모 → 실사용. **2주마다 재학습 → 새 GGUF.**

## 누적의 힘
| 기간 | 누적 | 수준 |
| --- | --- | --- |
| 오늘 | 30개 | 기본 페르소나 |
| 1개월 | 100개 | 자연스러움 |
| 6개월 | 700개 | "이거 본인이네" |
| 1년 | 1500개+ | **대체 불가 디지털 분신** |

- **데이터셋도 HF 백업**(`private=True`) → 새 모델 나오면 `load_dataset("내아이디/내데이터")` **1줄로 재학습.**

## 지식 자산화 (노하우·코드 → 데이터)
- 하나의 노하우 = **10~20개 Q&A** (5각도: 직접/상황/초보/반대/잡담).
- **코드 자체는 지식이 아니다** — 코드=결과물, 지식=의사결정. 5카테고리 추출(의사결정/삽질/패턴/함정/메타교훈).
- 회고 템플릿(프로젝트당 30분, 6질문) → AI 자동 추출로 1분 단축.
