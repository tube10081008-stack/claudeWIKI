# 학습 파라미터 (가중치 · 로스 · 하이퍼파라미터)

**한 줄 정의:** 모델을 학습시킬 때 조절하는 값들. 직접 실험하며 적절점을 찾는 것이 핵심 역량.

## 가중치 (Weight)
- 모델은 수학 모델: **y = w·x + b**.
- **W(가중치)** = 정답을 맞추기 위한 숫자(0.1, 0.001…). = 한국말 '매개변수(parameter)'.
- **Full Fine-tuning** = W 전체 변경(컴퓨팅 막대) / **LoRA** = 끝의 작은 행렬만 변경.

## Loss (로스)
- **정답값과 예측값의 차이.** 줄이는 것이 학습의 목표.
- 매 스텝 오르내리지만 **평균적으로 감소**해야 잘 학습되는 것.
- 정답값 = 내가 준 모범답안 / 예측값 = 모델이 생성한 값.

## 주요 하이퍼파라미터
| 파라미터 | 의미 (비유) |
| --- | --- |
| **learning_rate** | 학습 속도 (책 1권에 10초 vs 1년을 주기) |
| **max_steps** | 학습 횟수 (예: 30번은 실험용, 제대로는 더) |
| **per_device_train_batch_size** | 유효 배치 크기 (한 번에 볼 샘플 양 / 샘플링) |
| **max_sequence_length** | 한 번에 생성할 토큰 수 (클수록 비용↑) |

### ⭐ 핵심 3개 (6강 페르소나 파인튜닝 권장값)
| 파라미터 | 권장 | 의미 |
| --- | --- | --- |
| `learning_rate` | **3e-4** | 페르소나 덮어쓰기 강도 |
| `max_steps` | **60** | 학습 횟수 (30개 × 8 epoch) |
| `lora_alpha` | **32** | LoRA 강도 (rank r의 2배 권장) |

### Loss 해석 가이드
| Loss | 의미 | 조치 |
| --- | --- | --- |
| > 1.0 | 학습 부족 | step ↑ |
| **0.2~0.5** | ✅ 이상적 | 그대로 |
| < 0.01 | ⚠️ 과적합 | step ↓ |
> 상세 디버깅은 [파인튜닝 디버깅](./finetuning-debugging.md) 참고.

## 핵심
> 데이터 개수(30 → 100 → 1000), 학습 횟수, 학습 속도, 샘플링을 **막 실험해보는 것**이 실력.
> 너무 적으면 [과소적합, 너무 많으면 과적합](./overfitting-underfitting.md).
