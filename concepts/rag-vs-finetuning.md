# RAG vs 파인튜닝

**한 줄 정의:** 지식을 '검색해 가져오는' RAG vs 모델 '두뇌 자체를 바꾸는' 파인튜닝. 대체가 아니라 보완 관계.

## 비교
| | **RAG (오픈북)** | **파인튜닝 (두뇌 변경)** |
| --- | --- | --- |
| 방식 | 필요할 때 책을 **검색해 가져옴** | 책을 **보고 배워** 두뇌가 바뀜 |
| 모델 | 그대로 (Gemma 4 유지) | 모델 내부 변경 |
| 새 지식 | 즉시 추가·검색 (빠름) | 학습 필요(느림), 대신 내재화 |
| 매 질문 | 매번 검색·로딩 반복 | 이미 알고 있음 |
| 비유 | 면허증을 매번 찾아 읽음 | 한 번 보고 외워서 안 봐도 앎 |

## 핵심
> 두뇌(파인튜닝)는 두뇌의 뉴런 연결(전기 신호)이 바뀌는 것.
> RAG로 지식을 연결하면서 파인튜닝으로 두뇌를 특화하면, 검색·생성이 더 효율적이 된다.
