# 에이전트 오케스트레이션 (Agent Orchestration)

**한 줄 정의:** 여러 AI 에이전트를 지휘자처럼 조율해 협업시키는 것.

## 왜 필요한가
- 검색·추론·멀티모달 도구가 늘며 하나의 에이전트로 감당 불가 → 여러 에이전트로 분업.
- 지휘자(예: CEO 에이전트)가 "너는 이거, 너는 저거" 식으로 작업을 배분.

## 협업 구조 2종
| 구조 | 특징 |
| --- | --- |
| **Centralized (수직적)** | CEO→부장→과장… 중앙 지휘자가 명령 배분 |
| **Decentralized (수평적)** | 중앙이 없음. 모두가 평평하게 협업 |

## 모델 배분 원칙
- 에이전트마다 **목적에 맞는 다른 두뇌(모델)**를 써야 함.
- 멀티모달 하나로 다 하면 편하지만 **컴퓨테이션 낭비** → [모델 선택 = 자동차 엔진 고르기](./local-vs-cloud-llm.md).
