# 로컬 vs 클라우드 LLM

**한 줄 정의:** 모델을 남의 서버(클라우드 API)에서 쓰느냐, 내 컴퓨터(로컬)에서 쓰느냐의 차이.

## 비교
| | 클라우드 API (OpenAI/Gemini) | 로컬 LLM |
| --- | --- | --- |
| 보안 | ❌ 외부 통과 | ✅ 100% 내부 보관 |
| 비용 | 쓸 때마다 과금 | 초기 하드웨어 후 무료 |
| 커스터마이징 | ❌ 준 대로만 | ✅ 파인튜닝 가능 |
| 인터넷 | 필수 | 불필요(단절 가능) |
| 단점 | 가격·성능 변동성 | 좋은 GPU/RAM 필요 |

> 미래(2027~): 비용·보안 때문에 **SLM + RAG 로컬 구축**이 주류가 될 것.

## 모델 선택 = 자동차 엔진 고르기
- 에이전트마다 **목적에 맞는 모델**을 쓴다. (글=NLP, 이미지=Vision, 음악=Audio)
- 멀티모달 하나로 다 하면 **컴퓨테이션 낭비** → 60km 차에 페라리 엔진 넣지 말 것.
